Symplectic Learning of Physical Dynamics via Hamiltonian Pixel World Models
Axel Bröns

A continuous and symplectic pixel World Model that learns pendulum dynamics directly from raw video sequences. By combining a Hamiltonian Neural Network (HNN) with a 2nd-order symplectic integrator, the latent space strictly preserves energy conservation and phase space geometry without physical supervision.

Graph-Aware Transformers for Smart Contract Vulnerability Detection
Axel Bröns, Valentin Kocijancic, Antoine Goudedranche, Thibault Garel, Hugo Rivière, Omar El Alami El Fellousse

Automated detection of anomalies and fraudulent code in smart contracts using a graph-based approach combined with Transformers. The model achieves an F1 score of 0.81 and a recall of 0.91.

Detection of Academic Cognitive Stress Using Machine Learning
Axel Bröns, Anas Boutaleb, Omar El Alami El Fellousse

A research methodology for measuring and anticipating stress in academic environments. Using biomedical signal acquisition and supervised learning algorithms, we detect cognitive overload states with an 88.15% F1 score to help prevent burnout and academic dropout.
